## v1.2.8

### Added

#### AI 助理
- AI 助理可以透過 Homebrew 搜尋、安裝和解除安裝 App。只安裝 Homebrew 官方目錄中經過 Apple 公證的 App（命令列工具只允許來自 App 內部），安裝後還會再次檢查。
- 每次安裝和解除安裝前都會先請你確認。可在 設定 › AI 助理 中關閉，關閉後會顯示列出風險的警告。
- 未安裝 Homebrew 時，AppPad 會提示用官方安裝指令打開終端機。

#### 工作流程
- 新增內建工作流程「安裝 Homebrew」。

### Changed
- AI 助理: AI 觸發的確認視窗（安裝、解除安裝、儲存工作流程、執行、權限）現在顯示在最前面，且不會把 AppPad 的其他視窗帶到前面。

### Note
- 透過 Homebrew 解除安裝的 App 會直接刪除，不會丟到垃圾桶。
- 不支援 formula 和第三方 tap。只識別安裝在 /opt/homebrew 和 /usr/local 的 Homebrew。

## v1.2.7

### Added

#### 選單列
- 「檢查更新⋯」新增快速鍵 ⌘U。

### Fixed
- 選單列: 選單展開時按下的全域快速鍵（工作流程、剪貼簿、App 與視窗快速鍵）現在會立即收起選單並執行，不再等到選單關閉後才觸發。
- 選單列: 修正工作流程或剪貼簿開啟時，從選單按 ⌘, 開啟設定，面板背景會短暫變透明的問題。

## v1.2.4

### Added

#### AI 助理（MCP）
- 一鍵設定 Claude Desktop：新增「加入 Claude Desktop」和「從 Claude Desktop 移除」按鈕，並顯示目前狀態（已加入 / 未加入 / 未安裝）。只修改 claude_desktop_config.json 中 AppPad 自己的項目，其他 MCP 服務保持不變。

#### 工作流程
- 新增內建工作流程「將 AppPad 加入 Claude Desktop」和「從 Claude Desktop 移除 AppPad」，在工作流程面板輸入 “claude” 或 “mcp” 即可找到。

#### 歡迎指南
- AI 頁面也加入了 Claude Desktop 的加入 / 移除按鈕。

### Note
- 加入或移除 AppPad 後，需要重新啟動 Claude Desktop 才會生效。
- 未安裝 Claude Desktop 時不會加入任何內容，並會提示未安裝。
- 每次修改前，都會在同一位置把原檔案備份為 claude_desktop_config.json.apppad-backup。

## v1.1.6

### 新增

#### 歡迎導覽
- 首次啟動時，AppPad 現在會打開歡迎導覽而不是啟動台：先簡單介紹各項功能，再完成幾個設定步驟。每一步都可以略過，按 Esc 或 ⌘W 即可關閉導覽。
- 四指捏合：開啟或關閉此功能，查看需要關閉哪些 macOS 手勢及關閉順序，並一鍵打開觸控式軌跡板設定。
- 剪貼簿：開啟或關閉歷史記錄，查看其快速鍵和最實用的按鍵（⌘1–⌘0、⌘S、⌘↩），並了解點按某個 App 的圖像即可只顯示從該 App 拷貝的內容。
- 用 ⌘Space 打開工作流程：一鍵關閉 Spotlight 的快速鍵。變更立即生效，無需登出，並可在同一頁面復原。若無法自動變更，導覽會引導你前往鍵盤設定。
- App 快速鍵：一鍵為 Safari 設定 ⌃⌘J 來試試看，之後可在「設定 › App 快速鍵」中加入更多。
- 讓 AI 撰寫工作流程：開啟 AI 助理（MCP），拷貝 Claude Code 或其他用戶端的設定，並試用範例提示詞。AI 撰寫的每個工作流程仍需你核准。
- 權限與啟動：授予輔助使用權限（貼上和視窗控制需要）並開啟開機啟動，每一項都會顯示即時狀態。
- 最後一頁列出啟動台、剪貼簿、收藏和工作流程的快速鍵；點按「打開 AppPad」直接進入啟動台。
- 用兩指左右滑動，或點按、拖移底部的圓點，即可在頁面之間切換。
- 可隨時從「設定 › 關於 › 顯示歡迎導覽⋯」重新打開導覽。

### 變更
- 歡迎導覽取代了原本各自獨立的一次性捏合提示和 Spotlight 提示。若你之前已經看過這些提示，導覽不會自動打開。
- 自動更新會等到歡迎導覽關閉後再進行。

## v1.0.8

### 新增

#### 啟動台
- 解除安裝透過 Homebrew（`brew install --cask`）安裝的 App 時，現在也會將其從 Homebrew 中移除：App 及其殘留檔案移到垃圾桶後，AppPad 會為其 cask 執行 `brew uninstall --cask`。沒有安裝 Homebrew，或 App 不是 cask 時，行為不變。
- 若 Homebrew 無法自行完成（例如 cask 需要管理者密碼），AppPad 會顯示需要在「終端機」中執行的指令，並提供拷貝按鈕。

#### 工作流程
- 在工作流程面板中，輸入參數後的結果在有效時以綠色勾號開頭，無效時以紅色叉號開頭。

### 變更
- 從啟動台切換到剪貼簿或工作流程面板時，面板陰影現在會在變形過程中淡入，而不是在變形結束後才出現。
- 面板陰影改由 AppPad 繪製，並始終位於面板外側。使用半透明背景時，剪貼簿和工作流程面板現在與啟動台外觀完全一致：相同的模糊與透明度，不再額外變暗。
- 工作流程面板：有效的參數結果以一般文字顏色顯示，不再是綠色；無效結果仍為紅色。
- 在另一個面板打開時，從選單列選單選擇啟動台、剪貼簿或工作流程，現在與 ⌘⇧J / ⌘⇧K 的切換方式一致。

### 修正
- 用 ⌘⇧J / ⌘⇧K 在剪貼簿和工作流程面板之間切換時可能會閃爍一下。
- 在另一個面板打開時從選單列打開面板，會短暫露出桌面。

## v1.0.7

### 新增

#### AI 助理（MCP）
- Claude、Cursor 等 MCP 用戶端可以列出並執行你的工作流程，並像工作流程面板一樣傳入參數。結果會回傳給 AI，而不是以通知形式顯示。
- AI 助理也可以為你撰寫工作流程。每個新增或修改的工作流程都會完整顯示（包括腳本），只有在你點按「安裝」後才會儲存。
- 執行時使用與工作流程面板相同的確認和權限提示。已停用的工作流程保持隱藏。
- 設定中新增「AI 助理（MCP）」標籤頁，位於「工作流程」下方：預設開啟，顯示連線狀態，並提供 Claude Desktop、Cursor 和 Claude Code 的可直接拷貝的設定。
- 若 AppPad 未在執行，AI 用戶端會在背景啟動它，不會打開啟動台。

## v1.0.6

### 新增

#### 啟動台
- 搜尋保留檔案夾：檔案夾中的 App 現在會以其所在檔案夾的形式顯示。點按或按 ↩ 打開檔案夾，相符的 App 會反白顯示，再按 ↩ 即可打開它。
- 搜尋結果可以拖移：把 App 拖出面板，放到 Dock 或 Finder 中。
- 搜尋時建立檔案夾：把一個 App 緩慢放到另一個結果上即可建立新檔案夾，放到檔案夾上則加入該檔案夾。從搜尋結果中打開的檔案夾裡拖出的 App 也可以這樣放置。在面板邊緣停留即可翻到下一頁或上一頁結果。

### 變更
- 當檔案夾只剩一個 App 時，該 App 現在會從檔案夾中緩緩放大出來，而不是直接跳出。
- 搜尋時，若佈局發生變化（在檔案夾內重新排序、重新命名、解除安裝），打開的檔案夾、結果頁和選取項目都會保持不變；合併後結果維持原有順序，不再重新排序。

### 修正
- 在放下動畫期間點按（例如點按仍在形成中的檔案夾）可能會關閉啟動台。

## v1.0.5

### 新增

#### 自動更新
- AppPad 現在會自動保持最新。每天 4:00 檢查新版本，在背景下載，並在沒有面板打開時立即安裝，然後靜默重新啟動，不會打開啟動台。
- 因 Mac 處於睡眠或關機而錯過了檢查？AppPad 會在喚醒後不久補上；若網路尚未就緒，每 30 分鐘重試一次。
- 「設定 › 關於」中新增「更新」區塊：開啟或關閉自動更新（預設開啟）、選擇檢查時間、查看上次檢查時間，以及立即檢查。
- 選單列選單中新增「檢查更新⋯」。
- 若你在設定中時有更新正在等待，點按「重新啟動以更新」即可立即安裝。
- 更新在安裝前會透過 EdDSA 簽名驗證。

### 變更
- 「設定 › 關於」的致謝中列出了 Sparkle。

### 說明
- 1.0.5 之前的版本無法自動更新：請從 DMG 或透過 `brew upgrade --cask apppad` 安裝一次 1.0.5，之後的版本會自動更新。

## v1.0.3

### 新增

#### 剪貼簿
- 設定中新增「收藏」標籤頁，用於瀏覽、搜尋和管理收藏庫：每個項目都顯示來源 App 圖像、名稱、兩行預覽和日期，並附有「拷貝」和「移除」按鈕。
- 收藏的項目可以命名。在設定和剪貼簿面板中都可以搜尋名稱，已命名的項目在列表中以粗體顯示名稱。
- 在任一剪貼簿項目上按 ⌘↩，會在「設定 › 收藏」中打開它，並可直接輸入名稱；未收藏的項目會先被收藏。也可以從快速選單（「在收藏中編輯」）打開。

#### 備份與還原
- 備份現在包含項目名稱。舊備份照常還原；合併時，保留本機已設定的名稱。

### 變更
- 剪貼簿：刪除項目改為 ⌘⇧⌫（原為 ⌘⌫），這樣在搜尋欄中 ⌘⌫ 又可以刪除到行首了。
- 剪貼簿：「在 Finder 中顯示」從 ⌘↩ 改為 ⌘⇧↩。

## v1.0.2

### 新增

#### 工作流程
- 工作流程編輯器中新增「執行前詢問」選項：無論從工作流程面板或從設定中啟動，執行前都會跳出確認。
- 在工作流程面板中，確認會在面板內打開：↩ 執行，Esc 取消，其他按鍵會被忽略。按住或快速連按 ↩ 永遠不會確認。
- 工作流程格式新增選用欄位 `"confirm": true`；不含該欄位的現有檔案照常執行。

### 變更
- 內建的「結束所有 App」工作流程（v1.4）現在會要求確認，因此在工作流程面板中按 Tab 或 ↩ 不會再意外結束所有 App。

## v1.0.1

### 新增

#### 備份與還原
- 設定中新增「備份」標籤頁：匯出為單一 `.apppadbackup` 檔案，並可在本機或另一台 Mac 上還原。
- 可選擇要包含的內容：App 快速鍵（以及工作流程、剪貼簿和視窗快速鍵）、啟動台佈局及其格狀尺寸、已安裝的工作流程（包括圖像、面板快速鍵和開關狀態）、剪貼簿歷史記錄和收藏庫。
- 還原時會先顯示備份包含的內容，再做任何變更；可選擇要還原的部分，以及與現有內容合併或取代。
- 合併只補上缺少的內容：較新的工作流程版本會取代舊版本，剪貼簿項目依內容比對，不會產生重複。
- 啟動台佈局一律取代；本機未安裝的 App 會被略過，備份中沒有的 App 會加到最後。
- 鑰匙圈中的密鑰和「永遠允許」權限永遠不會寫入備份；還原的工作流程在首次執行時會重新要求權限。

## v1.0.0

首個公開版本。需要 macOS 26 Tahoe 或以上版本（通用版本：Apple 晶片 + Intel）。

### 新增

#### 啟動台
- 經典啟動台在 macOS 26+ 上回歸，沿用熟悉的預設佈局（不常用的系統 App 歸入「其他」檔案夾）。
- 透過四指捏合、選單列或點按 Dock 中的 AppPad 打開（再次點按關閉）。隨時點按即可取消捏合動畫。
- 兩指滑動翻頁；頁面指示器可顯示為圓點或數字，可點按，也可拖移快速瀏覽，並帶有「液態玻璃」透鏡效果。
- 即時搜尋，與 macOS 15 上的啟動台一樣；結果依每個 App 的使用頻率和最近使用時間排序。
- 長按 App 圖像或按住 ⌥ Option 進入編輯模式：拖移排序，把 App 放到另一個 App 上即可建立檔案夾。檔案夾可以橫跨多頁。
- 內建乾淨解除安裝：在編輯模式中刪除 App 時，AppPad 會一併清除其殘留檔案。
- 視窗大小跟隨螢幕，寬度和高度百分比分別設定；全尺寸時可覆蓋選單列，並避開瀏海。
- 在滑鼠所在的顯示器上打開（可選），並停留在打開時所在的空間，與原版啟動台一致。

#### 剪貼簿
- 文字和圖片的剪貼簿歷史永久保存；即使原始檔案被刪除，圖片也會保留。
- 常用項目的收藏庫：切換搜尋欄旁的「收藏」；收藏的項目在搜尋中排在最前。
- 用 ⌘. 打開（收藏庫：⌘⌥.），⌘1–⌘0 貼上，右側為預覽窗格。
- 每個項目都顯示來源 App 圖像，提供常用 App 的篩選標籤，以及 `AppName::` 搜尋語法。
- ⌘↩ 在 Finder 中顯示圖片的來源檔案夾。
- 依時間清理歷史（最近一小時、一天、一週⋯⋯一年以上），不影響收藏庫。

#### 工作流程
- 工作流程面板（⌘Space）可執行捷徑、AppleScript 和 Shell 腳本，並可在同一搜尋中啟動 App。
- 參數：在第一個空格後輸入，例如 `Set-Timer 10:00`。Tab 補全選取的項目。
- 內建工作流程：清空垃圾桶、設定倒數計時、設定鬧鐘、設定音量、靜音、結束所有 App，以及支援科學記號的計算機。
- 為 Shell 和 AppleScript 工作流程提供具備真正沙盒的權限系統：允許一次 / 不允許 / 永遠允許。
- 從 JSON 檔案或連結匯入工作流程，支援唯一 ID、版本修訂和多語言名稱。
- 每個工作流程可個別設定成功和失敗通知。
- App 和工作流程共用同一套使用頻率排序。

#### 視窗控制
- ⌃⌥← / ⌃⌥→ 靠左 / 靠右排列，在 ½ → ⅓ → ⅔ 之間循環。
- ⌃⌥↩ 最大化，⌃⌥⌫ 復原，⌃⌥⌘↑ / ⌃⌥⌘↓ 移到上一個 / 下一個顯示器。
- 所有快速鍵皆可自訂。

#### App 快速鍵
- 用全域快速鍵打開任意 App，提供 A–Z 排序的 App 列表和衝突偵測。

#### 外觀與一般
- 「液態玻璃」搜尋欄、頁面指示器和設定標籤頁。
- 主題：自動 / 淺色 / 深色。
- 背景：白色、淺灰色、深灰色、背景圖片或自訂顏色，淺色和深色主題各自擁有獨立的透明度和模糊設定。剪貼簿和工作流程面板可跟隨啟動台背景。
- ⌘⇧J / ⌘⇧K 在啟動台、剪貼簿和工作流程之間切換，帶有流暢的變形動畫。
- 僅顯示在選單列（除非你將其固定，否則不顯示 Dock 圖像），支援開機啟動。
- 可選在打開每個面板時切換到 ABC 輸入方式。
- 可設定 Esc 行為（立即關閉，或先清除搜尋）。
- 在地化為 10 種語言：English、Deutsch、Español、Français、Italiano、日本語、한국어、Nederlands、简体中文、繁體中文。
