AppPad의 주요 변경 사항은 모두 이 파일에 기록됩니다.
형식은 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)를 따르며, 이 프로젝트는 [유의적 버전](https://semver.org/)을 준수합니다.

> 이 문서는 [CHANGELOG.md](../../CHANGELOG.md)의 번역본입니다. 내용이 다를 경우 영어판을 기준으로 합니다.

## v1.3.7

### Changed
- 저장된 클립: 이름 필드가 날짜 앞까지 넓어지고 내용이 이름과 정렬됩니다. 내용 편집에서는 제목과 이름이 본문과 정렬됩니다.

### Fixed
- 설정: Launchpad, 워크플로, 클립보드, 메뉴 막대에서 열 때 설정 윈도우가 맨 앞으로 표시됩니다.
- 저장된 클립: 내용 편집이나 확인 창이 열려 있을 때도 ⌘Q 및 AppPad 종료가 작동합니다.

## v1.3.6

### Added

#### 설정
- 일반에 '패널 전환 화살표 표시' 스위치 추가: 클립보드와 워크플로 제목 옆의 ← / → 화살표를 표시하거나 숨깁니다. ⌘⇧K / ⌘⇧J로 계속 패널을 전환할 수 있습니다.
- 일반에 '단축키 힌트 표시' 스위치 추가: 클립보드와 워크플로 제목 아래의 단축키 줄을 표시하거나 숨깁니다. 끄면 제목이 검색 필드와 같은 줄에 놓입니다.
- 둘 다 기본으로 켜져 있습니다.

## v1.3.5

### Added

#### Launchpad
- Launchpad를 여는 키보드 단축키를 선택적으로 사용할 수 있습니다(기본값 ⌥스페이스, 기본적으로 꺼짐). 다시 누르면 닫힙니다. 설정 › AppPad › 단축키로 열기에서 켜고 변경할 수 있으며, 켜면 메뉴 막대 메뉴에도 표시됩니다.

#### 시작 가이드
- 오므리기 페이지에서 Launchpad 단축키를 켜고 Launchpad용 핫 코너를 선택할 수 있습니다.

### Changed
- 백업: 단축키 백업에 Launchpad 단축키도 포함됩니다.

## v1.3.4

### Added

#### Launchpad
- 빠른 페이지 넘기기(설정 › 일반, 기본값 끔): 두 손가락으로 짧게 쓸어넘기기만 해도 페이지가 넘어가고, 한 번에 여러 페이지를 넘길 수 있습니다. 위/아래로 쓸어넘기기도 똑같이 손가락을 따라갑니다.
- 빠른 페이지 넘기기를 켜면 페이지 점을 누른 채 드래그해 페이지를 연속으로 스크롤할 수 있으며, 손을 떼면 가장 가까운 페이지에 맞춰집니다. 폴더 안에서도 동작합니다.

### Changed
- Launchpad: 앞의 아이콘이 아직 제자리(예: 폴더)로 날아가는 중에도 다음 아이콘을 드래그할 수 있습니다. 애니메이션이 끝날 때까지 기다릴 필요가 없습니다.

## v1.3.3

### Added

#### 핫 코너
- 설정 › AppPad에 핫 코너가 추가되었습니다. 화면의 각 모서리에서 AppPad, 워크플로, 클립보드를 열거나 macOS 동작(Mission Control, 응용 프로그램 윈도우, 데스크탑, 알림 센터, 빠른 메모, 화면 보호기, 디스플레이 잠자기, 화면 잠금)을 실행할 수 있습니다.
- 동작을 선택할 때 ⌘, ⌥, ⌃ 또는 ⇧(조합 가능)를 누르고 있으면 그 모서리는 해당 키를 누르고 있을 때만 작동합니다(macOS와 동일).

### Note
- 알림 센터와 빠른 메모를 사용하려면 손쉬운 사용 권한이 필요합니다.
- macOS 핫 코너에도 같은 모서리가 설정되어 있으면 둘 다 실행됩니다. 이 경우 AppPad에 경고와 시스템 설정 바로가기가 표시됩니다.

## v1.3.2

### Added

#### 워크플로
- 새 내장 동작 '터미널 명령 미리 입력': 선택한 폴더에서 터미널을 열고 프롬프트에 명령을 입력해 둡니다. Return 키를 누르기 전에는 아무것도 실행되지 않습니다. `{{input}}`은 인수로 대치됩니다.

### Changed
- 워크플로: 'Homebrew 설치'는 이제 터미널에 공식 설치 명령을 미리 입력하기만 합니다. Return 키를 누르면 시작됩니다.
- 워크플로: 스크립트가 다른 앱을 제어하기 전에 AppPad가 먼저 macOS에 권한을 요청하므로, 해당 앱이 개인정보 보호 및 보안 › 자동화에 표시됩니다. 접근이 거부되면 워크플로가 명확한 메시지와 함께 중단됩니다.
- AI 어시스턴트: AI가 터미널 명령을 미리 입력하는 워크플로를 작성할 수 있습니다. AI를 통한 Homebrew 설치도 명령을 미리 입력하기만 합니다.

### Note
- 윈도우를 닫을 때 터미널이 실행 중인 프로세스를 종료할지 묻는다면, 터미널 설정(프로파일 › 셸 › 닫기 전에 묻기)에서 무시할 프로세스에 `zsh`를 추가하십시오.

## v1.3.1

### Added

#### 워크플로
- 새 기본 워크플로 'App Store 검색': `mas` 또는 `appstore` 뒤에 키워드를 입력하면 App Store에서 검색 결과를 바로 엽니다.

### Fixed

## v1.3.0

### Fixed
- 클립보드: AppPad에서 계산 결과를 복사하면 빈 자리 표시자 대신 AppPad 아이콘이 원본 앱으로 표시됩니다.

## v1.2.9

### Added

#### 워크플로
- 모든 워크플로에 출처가 표시됩니다: 내장(초록), 내 것(파랑, 직접 작성했거나 AI 어시스턴트가 저장한 것), 타사(주황, 가져온 웹사이트 또는 '가져온 파일').
- 워크플로 패널은 타사 항목에 주황색 아이콘을 표시하고, 미리보기에는 전체 링크와 가져온 시간이 나타납니다.
- 권한 요청 창에 워크플로의 출처가 표시되며, 타사 워크플로는 실행 확인 창에도 표시됩니다.

### Changed
- 워크플로: 내장 또는 타사 워크플로의 단계나 권한을 바꾸면 '수정됨'으로 표시되며, 타사 워크플로는 수정 후에도 타사로 유지됩니다.
- 워크플로: 다른 출처의 워크플로로 대체하면 AppPad가 권한을 다시 요청합니다.

### Fixed
- 워크플로: 가져온 워크플로가 같은 ID를 사용해 내장 워크플로를 대체할 수 있던 문제를 수정했습니다. 이제 건너뜁니다.
- 백업: 복원할 때 내장 워크플로를 더 이상 덮어쓰지 않으며, 켬/끔 상태와 패널 단축키만 복원합니다.

### Note
- 이 버전 이전에 추가한 내장이 아닌 워크플로는 출처가 기록되지 않아 '내 것'으로 표시됩니다.

## v1.2.8

### Added

#### AI 어시스턴트
- AI 어시스턴트가 Homebrew로 앱을 검색, 설치, 제거할 수 있습니다. Homebrew 공식 카탈로그에 있고 Apple의 공증을 받은 앱만 설치되며(명령줄 도구는 앱 내부의 것만), 설치 후 각 앱을 다시 확인합니다.
- 설치하거나 제거할 때마다 먼저 확인을 요청합니다. 설정 › AI 어시스턴트에서 끌 수 있으며, 이 경우 위험 사항을 나열한 경고가 표시됩니다.
- Homebrew가 없으면 공식 설치 명령으로 터미널을 열도록 제안합니다.

#### 워크플로
- 기본 워크플로 'Homebrew 설치'가 추가되었습니다.

### Changed
- AI 어시스턴트: AI가 띄우는 확인 창(설치, 제거, 워크플로 저장, 실행, 권한)이 AppPad의 다른 창을 앞으로 가져오지 않고 맨 앞에 표시됩니다.

### Note
- Homebrew로 제거한 앱은 휴지통으로 이동되지 않고 바로 삭제됩니다.
- Formula와 타사 tap은 지원하지 않습니다. Homebrew는 /opt/homebrew와 /usr/local에서만 인식됩니다.

## v1.2.7

### Added

#### 메뉴 막대
- '업데이트 확인…'에 ⌘U 단축키가 추가되었습니다.

### Fixed
- 메뉴 막대: 메뉴가 열린 상태에서 누른 전역 단축키(워크플로, 클립보드, 앱 및 윈도우 단축키)가 메뉴가 닫힐 때까지 기다리지 않고, 즉시 메뉴를 닫고 실행됩니다.
- 메뉴 막대: 워크플로 또는 클립보드가 열린 상태에서 메뉴에서 ⌘,로 설정을 열 때 패널 배경이 잠깐 투명해지던 문제를 수정했습니다.

## v1.2.6

### Fixed
- Launchpad: 격자의 행 또는 열 수를 바꿔도 더 이상 모든 페이지가 다시 정렬되지 않습니다. 격자를 키우면 원래 가득 찼던 페이지만 다음 페이지 앞쪽에서 아이콘을 가져오고, 가득 차지 않았던 페이지는 그대로 유지됩니다. 격자를 줄이면 들어가지 않는 아이콘이 다음 페이지 앞쪽으로 이동합니다.

## v1.2.5

### Changed
- Launchpad: App Store에서 다운로드 중인 앱의 아이콘을 불투명도 70%로 표시해 더 쉽게 알아볼 수 있습니다.

### Fixed
- Launchpad: App Store 다운로드가 끝날 때 앱 아이콘보다 먼저 빈 점선 상자가 잠깐 나타나던 문제를 수정했습니다. 이제 아이콘이 바로 전환됩니다.
- Launchpad: Homebrew로 설치했거나 응용 프로그램 폴더로 드래그한 앱이 더 이상 일반 앱 아이콘으로 먼저 표시되지 않습니다.

## v1.2.4

### Added

#### AI 어시스턴트(MCP)
- 클릭 한 번으로 Claude Desktop 설정: 「Claude Desktop에 추가」와 「Claude Desktop에서 제거」 버튼, 그리고 현재 상태(추가됨 / 추가되지 않음 / 설치되지 않음)를 표시합니다. claude_desktop_config.json에서 AppPad 항목만 변경하며, 다른 MCP 서버는 그대로 유지됩니다.
- 추가한 뒤 AppPad를 옮긴 경우 상태에 표시되며, 「Claude Desktop에 추가」로 경로를 업데이트할 수 있습니다.

#### 워크플로
- 새 기본 워크플로 「Claude Desktop에 AppPad 추가」와 「Claude Desktop에서 AppPad 제거」. 워크플로 패널에서 「claude」 또는 「mcp」를 입력하면 찾을 수 있습니다.

#### 시작 가이드
- AI 페이지에도 Claude Desktop 추가 / 제거 버튼이 생겼습니다.

### Note
- AppPad를 추가하거나 제거한 후 Claude Desktop을 다시 시작해야 적용됩니다.
- Claude Desktop이 설치되어 있지 않으면 아무것도 추가하지 않고 이를 알려 줍니다.
- 변경할 때마다 이전 파일의 백업을 같은 위치에 claude_desktop_config.json.apppad-backup으로 저장합니다.

## v1.1.9

### 추가
- Launchpad: 앱 아이콘에 Dock과 같은 빨간 배지(읽지 않은 개수, 업데이트 등)가 표시됩니다. 폴더에는 안에 있는 앱 배지 숫자의 합계가 표시되며, 안에 있는 앱에 텍스트 배지만 있으면 빨간 점이 표시됩니다.
- 설정 › 일반: 새로운 '앱 배지 표시' 스위치를 추가했습니다(기본값: 켬). 배지는 Dock에서 읽어 오므로 손쉬운 사용 권한이 필요합니다. 권한이 없으면 스위치 옆에 안내 문구와 시스템 설정을 여는 버튼이 표시됩니다.

## v1.1.6

### 추가

#### 환영 가이드
- 처음 실행하면 AppPad가 Launchpad 대신 환영 가이드를 엽니다. 기능을 간단히 둘러본 뒤 몇 가지 설정 단계를 진행합니다. 모든 단계는 건너뛸 수 있으며, Esc 또는 ⌘W로 가이드를 닫을 수 있습니다.
- 네 손가락 오므리기: 켜거나 끄고, 꺼야 할 macOS 제스처와 그 순서를 확인하며, 클릭 한 번으로 트랙패드 설정을 열 수 있습니다.

- 병합은 빠진 것만 추가합니다. 더 새로운 버전의 워크플로가 이전 버전을 대체하고, 클립보드 항목은 내용으로 비교하므로 중복되지 않습니다.
- Launchpad 배치는 항상 대체됩니다. 이 Mac에 설치되지 않은 앱은 건너뛰고, 백업에 없는 앱은 끝에 추가됩니다.
- 키체인 비밀 정보와 '항상 허용' 권한은 백업에 절대 기록되지 않으며, 복원된 워크플로는 처음 실행할 때 다시 권한을 요청합니다.

## v1.0.0

첫 공개 릴리스입니다. macOS 26 Tahoe 이상이 필요합니다(Universal: Apple 실리콘 + Intel).

### 추가

#### Launchpad
- 익숙한 기본 배치(자주 쓰지 않는 시스템 앱은 '기타' 폴더에 모아 둠)와 함께 클래식 Launchpad가 macOS 26+에 돌아왔습니다.
- 네 손가락 오므리기, 메뉴 막대 또는 Dock의 AppPad 클릭으로 엽니다(다시 클릭하면 닫힘). 오므리기 애니메이션은 언제든 클릭으로 취소할 수 있습니다.
- 두 손가락으로 쓸어 넘겨 페이지 이동. 페이지 표시기는 점 또는 숫자로 표시되며, 탭하거나 Liquid Glass 렌즈로 드래그해 빠르게 넘길 수 있습니다.
- macOS 15의 Launchpad처럼 즉시 검색되며, 결과는 각 앱의 사용 빈도와 최근 사용 순으로 정렬됩니다.
- 앱 아이콘을 길게 누르거나 ⌥ Option을 누른 채로 편집 모드: 드래그로 순서를 바꾸고, 앱을 다른 앱 위에 놓아 폴더를 만듭니다. 폴더는 여러 페이지에 걸칠 수 있습니다.
- 깔끔한 제거 기능 내장: 편집 모드에서 앱을 삭제하면 AppPad가 남은 파일까지 함께 제거합니다.
- 창 크기는 화면에 맞춰지며 너비와 높이 비율을 각각 설정할 수 있습니다. 최대 크기에서는 메뉴 막대를 덮을 수 있고 노치는 피해 갑니다.
- 마우스가 있는 디스플레이에서 열리며(선택 사항), 원래 Launchpad처럼 연 스페이스에 머무릅니다.

#### 클립보드
- 텍스트와 이미지의 클립보드 기록을 영구 보관합니다. 원본 파일이 삭제되어도 이미지는 남습니다.
- 자주 쓰는 항목을 위한 저장 보관함: 검색 필드 옆의 '저장됨'을 전환합니다. 저장된 항목은 검색에서 가장 먼저 표시됩니다.
- ⌘.로 열기(저장 보관함: ⌘⌥.), ⌘1–⌘0으로 붙여넣기, 오른쪽에 미리보기 창.
- 모든 항목에 원본 앱 아이콘이 표시되며, 자주 쓰는 앱 필터 칩과 `AppName::` 검색 문법을 제공합니다.
- ⌘↩로 이미지의 원본 폴더를 Finder에서 보여 줍니다.
- 저장 보관함은 건드리지 않고 기간별(지난 1시간, 1일, 1주 … 1년 이상)로 기록을 정리할 수 있습니다.

#### 워크플로
- 워크플로 패널(⌘Space)에서 단축어, AppleScript, 셸 스크립트를 실행하고 같은 검색에서 앱도 실행할 수 있습니다.
- 인자: 첫 번째 공백 뒤에 입력합니다(예: `Set-Timer 10:00`). Tab으로 선택한 항목을 자동 완성합니다.
- 내장 워크플로: 휴지통 비우기, 타이머 설정, 알람 설정, 음량 설정, 음소거, 모든 앱 종료, 그리고 과학적 표기법을 지원하는 계산기.
- 셸 및 AppleScript 워크플로를 위한 실제 샌드박스 기반 권한 시스템: 한 번 허용 / 허용 안 함 / 항상 허용.
- JSON 파일이나 링크에서 워크플로 가져오기. 고유 ID, 리비전, 다국어 이름을 지원합니다.
- 워크플로별 성공 및 실패 알림.
- 앱과 워크플로가 하나의 사용 빈도 순위를 공유합니다.

#### 윈도우 제어
- ⌃⌥← / ⌃⌥→로 왼쪽 / 오른쪽에 맞추기, ½ → ⅓ → ⅔ 순으로 전환.
- ⌃⌥↩ 최대화, ⌃⌥⌫ 복원, ⌃⌥⌘↑ / ⌃⌥⌘↓ 이전 / 다음 디스플레이로 이동.
- 모든 단축키를 사용자 지정할 수 있습니다.

#### 앱 단축키
- 어떤 앱이든 여는 전역 단축키. A–Z 앱 목록과 충돌 감지를 제공합니다.

#### 외관 및 일반
- Liquid Glass 검색 필드, 페이지 표시기, 설정 탭.
- 테마: 자동 / 라이트 / 다크.
- 배경: 흰색, 연한 회색, 진한 회색, 배경화면 또는 사용자화 색상. 라이트와 다크 테마마다 투명도와 흐림을 따로 설정할 수 있습니다. 클립보드와 워크플로 패널은 Launchpad 배경을 따를 수 있습니다.
- ⌘⇧J / ⌘⇧K로 Launchpad, 클립보드, 워크플로 사이를 부드러운 모핑 애니메이션으로 전환합니다.
- 메뉴 막대에만 표시(고정하지 않는 한 Dock 아이콘 없음), 로그인 시 실행.
- 각 패널을 열 때 ABC 입력 소스로 전환하는 옵션.
- Esc 동작 설정(바로 닫기 또는 먼저 검색어 지우기).
- 10개 언어로 현지화: English, Deutsch, Español, Français, Italiano, 日本語, 한국어, Nederlands, 简体中文, 繁體中文.
