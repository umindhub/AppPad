## v1.2.0

### Changed
- 启动台：点击应用时，启动台现在会和点击空白位置一样放大并渐隐消失，不再瞬间消失。

## v1.1.9

### 新增
- 启动台：App 图标现在会显示与程序坞相同的红色标记（未读数、更新等）。文件夹显示其中各 App 标记数字的总和；如果其中的 App 只有文字标记，则显示一个红点。
- 设置 › 通用：新增“显示 App 标记”开关，默认开启。标记从程序坞读取，需要辅助功能权限；未授权时，开关处会显示提示，并附带打开系统设置的按钮。

## v1.1.8

### 变更
- 外观：优化了按钮形状和开关颜色。
- 快捷键：提升了快捷键列表的性能。
- 收藏：调整了重复剪切板条目的处理方式。

### 修复
- 修复了设置左侧宽度时的问题。

## v1.1.7

### 变更
- 外观：所有开关统一为绿色，所有按钮统一为相同的胶囊形状。
- 卸载：优化了删除确认页面。

## v1.1.6

### 新增

#### 欢迎引导
- 首次启动时，AppPad 现在会打开欢迎引导而不是启动台：先简要介绍各项功能，再完成几步设置。每一步都可以跳过，按 Esc 或 ⌘W 即可关闭引导。
- 四指捏合：开启或关闭该功能，查看需要关闭哪些 macOS 手势及关闭顺序，并一键打开触控板设置。
- 剪切板：开启或关闭历史记录，查看其快捷键和最常用的按键（⌘1–⌘0、⌘S、⌘↩），并了解点击某个 App 的图标即可只显示从该 App 复制的内容。
- 用 ⌘Space 打开工作流：一键关闭聚焦搜索的快捷键。更改立即生效，无需注销，并可在同一页面撤销。如果无法自动更改，引导会指引你前往键盘设置。
- App 快捷键：一键为 Safari 设置 ⌃⌘J 来体验一下，之后可在“设置 › App 快捷键”中添加更多。
- 让 AI 编写工作流：开启 AI 助手（MCP），复制 Claude Code 或其他客户端的配置，并试用示例提示词。AI 编写的每个工作流仍需你批准。
- 权限与启动：授予辅助功能权限（粘贴和窗口控制需要）并开启开机启动，每一项都会显示实时状态。
- 最后一页列出启动台、剪切板、收藏和工作流的快捷键；点击“打开 AppPad”直接进入启动台。
- 用两指左右轻扫，或点击、拖动底部的圆点，即可在页面之间切换。
- 可随时从“设置 › 关于 › 显示欢迎引导…”重新打开引导。

### 变更
- 欢迎引导取代了原先单独的一次性捏合提示和聚焦提示。如果你之前已经看过这些提示，引导不会自动打开。
- 自动更新会等到欢迎引导关闭后再进行。

## v1.1.5

### 变更

### 修复
- 启动台：用 ↩ 重命名文件夹后，名称不再向左偏移。

## v1.1.4

### 修复
- 修复：新安装的 App（例如通过 Homebrew 安装）在重启 AppPad 之前可能显示为空白图标。

## v1.1.3

### 新增
- 启动台：正在从 App Store 下载的 App 会立即出现，以变暗样式和进度条显示，安装完成后恢复正常。
- 启动台：删除 App 时，其图标下方会显示进度条；完成后图标消失。

### 变更
- 卸载：保留沙盒容器中的 App 设置和数据，与在访达中删除时相同，重新安装即可恢复。

### 修复
- 卸载：App Store 的 App 以及其他归系统所有的 App 又可以删除了（访达会请求你的密码或触控 ID）。`/Library` 中的残留文件也以同样方式删除。
- 卸载：该 App 仍在运行的小组件和扩展不再阻止删除。

## v1.1.1

## v1.1.0

## v1.0.9

### 新增

#### 启动台
- 搜索现在也能按名称找到文件夹，与 App 一样支持拼音和首字母。
- 用 `|` 或 `||` 同时搜索多项，例如 `WeChat | Social` 会同时显示该 App 和该文件夹，你可以直接把 App 拖进文件夹。

### 变更
- AppPad 现在支持 macOS 15 Sequoia 及更高版本（此前需要 macOS 26 Tahoe 或更高版本）。“液态玻璃”控件仍在 macOS 26 及更高版本上提供。

## v1.0.8

### 新增

#### 启动台
- 卸载通过 Homebrew（`brew install --cask`）安装的 App 时，现在也会将其从 Homebrew 中移除：App 及其残留文件移入废纸篓后，AppPad 会为其 cask 运行 `brew uninstall --cask`。没有安装 Homebrew，或 App 不是 cask 时，行为不变。
- 如果 Homebrew 无法自行完成（例如 cask 需要管理员密码），AppPad 会显示需要在终端中运行的命令，并提供复制按钮。

#### 工作流
- 在工作流面板中，输入参数后的结果在有效时以绿色对勾开头，无效时以红色叉号开头。

### 变更
- 从启动台切换到剪切板或工作流面板时，面板阴影现在会在变形过程中渐显，而不是在变形结束后才出现。
- 面板阴影改由 AppPad 绘制，并始终位于面板外侧。使用半透明背景时，剪切板和工作流面板现在与启动台外观完全一致：相同的模糊与透明度，不再额外变暗。
- 工作流面板：有效的参数结果以正常文字颜色显示，不再是绿色；无效结果仍为红色。
- 在另一个面板打开时，从菜单栏菜单选择启动台、剪切板或工作流，现在与 ⌘⇧J / ⌘⇧K 的切换方式一致。

### 修复
- 用 ⌘⇧J / ⌘⇧K 在剪切板和工作流面板之间切换时可能会闪烁一下。
- 在另一个面板打开时从菜单栏打开面板，会短暂露出桌面。

## v1.0.7

### 新增

#### AI 助手（MCP）
- Claude、Cursor 等 MCP 客户端可以列出并运行你的工作流，并像工作流面板一样传入参数。结果会返回给 AI，而不是以通知形式显示。
- AI 助手还可以为你编写工作流。每个新增或修改的工作流都会完整展示（包括脚本），只有在你点击“安装”后才会保存。
- 运行时使用与工作流面板相同的确认和权限提示。已停用的工作流保持隐藏。
- 设置中新增“AI 助手（MCP）”标签页，位于“工作流”下方：默认开启，显示连接状态，并提供 Claude Desktop、Cursor 和 Claude Code 的可直接复制的配置。
- 如果 AppPad 未在运行，AI 客户端会在后台启动它，不会打开启动台。

## v1.0.6

### 新增

#### 启动台
- 搜索保留文件夹：文件夹中的 App 现在会以其所在文件夹的形式显示。点击或按 ↩ 打开文件夹，匹配的 App 会高亮显示，再按 ↩ 即可打开它。
- 搜索结果可以拖动：把 App 拖出面板，放到程序坞或访达中。
- 搜索时创建文件夹：把一个 App 缓慢放到另一个结果上即可新建文件夹，放到文件夹上则加入该文件夹。从搜索结果中打开的文件夹里拖出的 App 也可以这样放置。在面板边缘停留即可翻到下一页或上一页结果。

### 变更
- 当文件夹只剩一个 App 时，该 App 现在会从文件夹中缓缓放大出来，而不是直接弹出。
- 搜索时，如果布局发生变化（在文件夹内重新排序、重命名、卸载），打开的文件夹、结果页和选中项都会保持不变；合并后结果保持原有顺序，不再重新排序。

### 修复
- 在放下动画期间点击（例如点击仍在形成中的文件夹）可能会关闭启动台。

## v1.0.5

### 新增

#### 自动更新
- AppPad 现在会自动保持最新。每天 4:00 检查新版本，在后台下载，并在没有面板打开时立即安装，然后静默重启，不会打开启动台。
- 因 Mac 处于睡眠或关机而错过了检查？AppPad 会在唤醒后不久补上；如果网络尚未就绪，每 30 分钟重试一次。
- “设置 › 关于”中新增“更新”部分：开启或关闭自动更新（默认开启）、选择检查时间、查看上次检查时间，以及立即检查。
- 菜单栏菜单中新增“检查更新…”。
- 如果你在设置中时有更新正在等待，点击“重启以更新”即可立即安装。
- 更新在安装前会通过 EdDSA 签名验证。

### 变更
- “设置 › 关于”的致谢中列出了 Sparkle。

### 说明
- 1.0.5 之前的版本无法自动更新：请从 DMG 或通过 `brew upgrade --cask apppad` 安装一次 1.0.5，之后的版本会自动更新。

## v1.0.4

### 新增
- 收藏：文字条目现在除了名称，内容也可以编辑。点击文字打开编辑器；⌘↩ 保存，Esc 取消。如果编辑后会与另一条目重复，则不予保存。

### 变更
- 收藏：复制成功后，“复制”按钮会短暂变为绿色对勾；行高保持不变。

### 修复
- 收藏：复制条目不再把其来源 App 改为 AppPad。复制现在计为一次使用（与从剪切板面板粘贴相同），并将该条目移到历史记录顶部。

## v1.0.3

### 新增

#### 剪切板
- 设置中新增“收藏”标签页，用于浏览、搜索和管理收藏库：每个条目都显示来源 App 图标、名称、两行预览和日期，并带有“复制”和“移除”按钮。
- 收藏的条目可以命名。在设置和剪切板面板中都可以搜索名称，已命名的条目在列表中以粗体显示名称。
- 在任意剪切板条目上按 ⌘↩，会在“设置 › 收藏”中打开它，并可直接输入名称；未收藏的条目会先被收藏。也可以从右键菜单（“在收藏中编辑”）打开。

#### 备份与恢复
- 备份现在包含条目名称。旧备份照常恢复；合并时，保留本机已设置的名称。

### 变更
- 剪切板：删除条目改为 ⌘⇧⌫（原为 ⌘⌫），这样在搜索框中 ⌘⌫ 又可以删除到行首了。
- 剪切板：“在访达中显示”从 ⌘↩ 改为 ⌘⇧↩。

## v1.0.2

### 新增

#### 工作流
- 工作流编辑器中新增“运行前询问”选项：无论从工作流面板还是从设置中启动，运行前都会弹出确认。
- 在工作流面板中，确认会在面板内打开：↩ 运行，Esc 取消，其他按键会被忽略。按住或快速连按 ↩ 永远不会确认。
- 工作流格式新增可选字段 `"confirm": true`；不含该字段的现有文件照常运行。

### 变更
- 内置的“退出所有应用”工作流（v1.4）现在会请求确认，因此在工作流面板中按 Tab 或 ↩ 不会再意外退出所有 App。

## v1.0.1

### 新增

#### 备份与恢复
- 设置中新增“备份”标签页：导出为单个 `.apppadbackup` 文件，并可在本机或另一台 Mac 上恢复。
- 可选择要包含的内容：App 快捷键（以及工作流、剪切板和窗口快捷键）、启动台布局及其网格尺寸、已安装的工作流（包括图标、面板快捷键和开关状态）、剪切板历史记录和收藏库。
- 恢复时会先显示备份包含的内容，再做任何更改；可选择要恢复的部分，以及与现有内容合并还是替换。
- 合并只补充缺失的内容：较新的工作流版本会替换旧版本，剪切板条目按内容匹配，不会产生重复。
- 启动台布局总是被替换；本机未安装的 App 会被跳过，备份中没有的 App 会添加到末尾。
- 钥匙串中的密钥和“始终允许”权限永远不会写入备份；恢复的工作流在首次运行时会重新请求权限。

## v1.0.0

首个公开版本。需要 macOS 26 Tahoe 或更高版本（通用版本：Apple 芯片 + Intel）。

### 新增

#### 启动台
- 经典启动台在 macOS 26+ 上回归，沿用熟悉的默认布局（不常用的系统 App 归入“其他”文件夹）。
- 通过四指捏合、菜单栏或点击程序坞中的 AppPad 打开（再次点击关闭）。随时点击即可取消捏合动画。
- 两指轻扫翻页；页面指示器可显示为圆点或数字，可点击，也可拖动快速浏览，并带有“液态玻璃”透镜效果。
- 即时搜索，与 macOS 15 上的启动台一样；结果按每个 App 的使用频率和最近使用时间排序。
- 长按 App 图标或按住 ⌥ Option 进入编辑模式：拖动排序，把 App 放到另一个 App 上即可创建文件夹。文件夹可以跨多页。
- 内置干净卸载：在编辑模式下删除 App 时，AppPad 会一并清理其残留文件。
- 窗口大小跟随屏幕，宽度和高度百分比分别设置；全尺寸时可覆盖菜单栏，并避开刘海。
- 在鼠标所在的显示器上打开（可选），并停留在打开时所在的空间，与原版启动台一致。

#### 剪切板
- 文字和图片的剪切板历史永久保存；即使原文件被删除，图片也会保留。
- 常用条目的收藏库：切换搜索框旁的“收藏”；收藏的条目在搜索中排在最前。
- 用 ⌘. 打开（收藏库：⌘⌥.），⌘1–⌘0 粘贴，右侧为预览窗格。
- 每个条目都显示来源 App 图标，提供常用 App 的筛选标签，以及 `AppName::` 搜索语法。
- ⌘↩ 在访达中显示图片的来源文件夹。
- 按时间清理历史（最近一小时、一天、一周……一年以上），不影响收藏库。

#### 工作流
- 工作流面板（⌘Space）可运行快捷指令、AppleScript 和 Shell 脚本，并可在同一搜索中启动 App。
- 参数：在第一个空格后输入，例如 `Set-Timer 10:00`。Tab 补全选中的条目。
- 内置工作流：清倒废纸篓、设置倒计时、设置闹钟、设置音量、静音、退出所有应用，以及支持科学计数法的计算器。
- 为 Shell 和 AppleScript 工作流提供带真实沙盒的权限系统：允许一次 / 不允许 / 始终允许。
- 从 JSON 文件或链接导入工作流，支持唯一 ID、版本修订和多语言名称。
- 每个工作流可单独设置成功和失败通知。
- App 和工作流共用同一套使用频率排序。

#### 窗口控制
- ⌃⌥← / ⌃⌥→ 靠左 / 靠右排列，在 ½ → ⅓ → ⅔ 之间循环。
- ⌃⌥↩ 最大化，⌃⌥⌫ 恢复，⌃⌥⌘↑ / ⌃⌥⌘↓ 移到上一个 / 下一个显示器。
- 所有快捷键均可自定义。

#### App 快捷键
- 用全局快捷键打开任意 App，提供 A–Z 排序的 App 列表和冲突检测。

#### 外观与通用
- “液态玻璃”搜索框、页面指示器和设置标签页。
- 主题：自动 / 浅色 / 深色。
- 背景：白色、浅灰色、深灰色、壁纸或自定颜色，浅色和深色主题各自拥有独立的透明度和模糊设置。剪切板和工作流面板可跟随启动台背景。
- ⌘⇧J / ⌘⇧K 在启动台、剪切板和工作流之间切换，带有流畅的变形动画。
- 仅显示在菜单栏（除非你将其固定，否则不显示程序坞图标），支持开机启动。
- 可选在打开每个面板时切换到 ABC 输入法。
- 可配置 Esc 行为（立即关闭，或先清空搜索）。
- 本地化为 10 种语言：English、Deutsch、Español、Français、Italiano、日本語、한국어、Nederlands、简体中文、繁體中文。

#### 分发
- 使用 Developer ID 签名并经过 Apple 公证。
- 通过 Homebrew 安装：`brew tap umindhub/tap && brew trust umindhub/tap && brew install --cask apppad`。
- 源代码采用 AGPL-3.0 协议。内置工作流、工作流格式和第三方工作流采用 MIT 协议。
