## v1.3.7

### Changed
- 保存済みクリップ: 名前フィールドが日付の手前まで広がり、内容が名前とそろうようになりました。「内容を編集」ではタイトルと名前が本文とそろいます。

### Fixed
- 設定: Launchpad、ワークフロー、クリップボード、メニューバーから開いたときに設定ウインドウが最前面に表示されるようになりました。
- 保存済みクリップ: 「内容を編集」や確認ダイアログを表示中でも ⌘Q と「AppPad を終了」が使えるようになりました。

## v1.3.6

### Added

#### 設定
- 一般に「パネル切り替え矢印を表示」スイッチを追加：クリップボードとワークフローのタイトル横の ← / → 矢印を表示 / 非表示にします。⌘⇧K / ⌘⇧J でのパネル切り替えはそのまま使えます。
- 一般に「ショートカットのヒントを表示」スイッチを追加：クリップボードとワークフローのタイトル下のショートカット行を表示 / 非表示にします。オフのときは、タイトルが検索フィールドと同じ高さに並びます。
- どちらもデフォルトでオンです。

## v1.3.5

### Added

#### Launchpad
- Launchpad を開くキーボードショートカットを追加しました（デフォルトは ⌥スペース、初期設定はオフ）。もう一度押すと閉じます。設定 › AppPad › ショートカットで開く でオン／変更でき、オンにするとメニューバーのメニューにも表示されます。

#### ようこそガイド
- ピンチのページで、Launchpad のショートカットをオンにしたり、Launchpad 用のホットコーナーを選んだりできるようになりました。

### Changed
- バックアップ: ショートカットのバックアップに Launchpad のショートカットも含まれるようになりました。

## v1.3.4

### Added

#### Launchpad
- 高速ページめくり（設定 › 一般、デフォルトはオフ）：2本指で短くスワイプするだけでページがめくれ、1回のスワイプで複数ページ移動できます。上下のスワイプも同じように指に追従します。
- 高速ページめくりがオンのとき、ページドットを押したままドラッグするとページが連続的にスクロールし、離すと最も近いページに収まります。フォルダ内でも使えます。

### Changed
- Launchpad：前のアイコンが所定の位置（フォルダなど）へ移動している最中でも、次のアイコンをドラッグできるようになりました。アニメーションの終了を待つ必要はありません。

## v1.3.3

### Added

#### ホットコーナー
- 設定 › AppPad にホットコーナーを追加しました。画面の各隅で AppPad、ワークフロー、クリップボードを開いたり、macOS の操作（ミッションコントロール、アプリケーションウインドウ、デスクトップ、通知センター、クイックメモ、スクリーンセーバ、ディスプレイのスリープ、画面をロック）を実行したりできます。
- 操作を選ぶときに ⌘、⌥、⌃、⇧（組み合わせ可）を押していると、その隅はそれらのキーを押している間だけ反応します（macOS と同じ）。

### Note
- 通知センターとクイックメモにはアクセシビリティの許可が必要です。
- macOS のホットコーナーにも同じ隅が設定されていると両方が実行されます。その場合 AppPad に警告とシステム設定へのボタンが表示されます。

## v1.3.2

### Added

#### ワークフロー
- 新しい内蔵アクション「ターミナルにコマンドを事前入力」：指定したフォルダでターミナルを開き、プロンプトにコマンドを入力した状態にします。returnキーを押すまで何も実行されません。`{{input}}` は引数に置き換えられます。

### Changed
- ワークフロー：「Homebrewをインストール」はターミナルに公式インストールコマンドを入力するだけになりました。returnキーを押すと開始します。
- ワークフロー：スクリプトが他のアプリを制御する前に、AppPadがまずmacOSに許可を求めるため、そのアプリが「プライバシーとセキュリティ」›「オートメーション」に表示されます。拒否された場合はワークフローが停止し、分かりやすいメッセージが表示されます。
- AIアシスタント：AIがターミナルにコマンドを事前入力するワークフローを作成できるようになりました。AIによるHomebrewのインストールもコマンドを入力するだけです。

### Note
- ウインドウを閉じるときにターミナルが実行中のプロセスを終了するか尋ねる場合は、ターミナルの設定（プロファイル › シェル › 閉じる前に確認）で、無視するプロセスに `zsh` を追加してください。

## v1.2.9

### Added

#### ワークフロー
- 各ワークフローに提供元を表示します：内蔵（緑）、自作（青。自分で書いたもの、または AI アシスタントが保存したもの）、サードパーティ（オレンジ。入手元の Web サイト、または「読み込んだファイル」）。
- ワークフローパネルではサードパーティの行にオレンジのアイコンが付き、プレビューには完全なリンクと読み込み日時が表示されます。

### Note
- このバージョンより前に追加した内蔵以外のワークフローは、提供元が記録されていないため「自作」と表示されます。

## v1.2.8

### Added

#### AI アシスタント
- AIアシスタントがHomebrewでアプリを検索・インストール・アンインストールできるようになりました。インストールされるのは、Homebrew公式カタログにありAppleの公証を受けたアプリだけです（コマンドラインツールはアプリ内のもののみ）。インストール後にも各アプリを再確認します。
- インストールとアンインストールのたびに事前に確認します。設定 › AI アシスタントでオフにでき、その場合はリスクを列挙した警告が表示されます。
- Homebrewが未インストールの場合、公式のインストールコマンドでターミナルを開くことを提案します。

#### ワークフロー
- 内蔵ワークフロー「Homebrewをインストール」を追加しました。

### Changed
- AI アシスタント: AIが起こす確認（インストール、アンインストール、ワークフローの保存、実行、権限）が、AppPadのほかのウインドウを前面に出さずに最前面に表示されるようになりました。

### Note
- Homebrewでアンインストールしたアプリはゴミ箱に入らず、すぐに削除されます。
- Formulaとサードパーティのtapには対応していません。Homebrewは/opt/homebrewと/usr/localでのみ検出されます。

## v1.1.6

### 追加

#### ウェルカムガイド
- 初回起動時、AppPad は Launchpad の代わりにウェルカムガイドを開くようになりました。機能を簡単に紹介したあと、いくつかの設定ステップに進みます。どのステップもスキップでき、Esc または ⌘W でガイドを閉じられます。
- 4 本指のピンチ：オン / オフの切り替え、オフにすべき macOS のジェスチャとその順序の確認、ワンクリックでトラックパッド設定を開くことができます。
- クリップボード：履歴のオン / オフ、ショートカットと特に便利なキー（⌘1–⌘0、⌘S、⌘↩）の確認、そしてアプリのアイコンをクリックするとそのアプリからコピーした内容だけが表示されることを紹介します。
- ⌘Space でワークフロー：Spotlight のショートカットをワンクリックでオフにできます。変更はログアウトせずにすぐ反映され、同じページで元に戻せます。自動で変更できない場合は、キーボード設定へ案内します。
- アプリのショートカット：ワンクリックで Safari に ⌃⌘J を割り当てて試せます。その後は「設定 › アプリのショートカット」で追加できます。
- AI がワークフローを作成：AI アシスタント（MCP）をオンにし、Claude Code などのクライアント用の設定をコピーして、サンプルのプロンプトを試せます。AI が作成したワークフローは、すべてあなたの承認が必要です。
- 権限と起動：アクセシビリティの権限（ペーストとウインドウ操作に必要）を許可し、ログイン時の起動をオンにできます。それぞれの状態がリアルタイムで表示されます。
- 最後のページには Launchpad、クリップボード、保存済み項目、ワークフローのショートカットが一覧表示され、「AppPad を開く」で直接 Launchpad に移動します。
- 2 本指で左右にスワイプするか、下部のドットをクリックまたはドラッグしてページを移動できます。
- 「設定 › 情報 › ウェルカムガイドを表示…」からいつでもガイドを再表示できます。

### 変更
- ウェルカムガイドは、これまで個別に表示されていた 1 回限りのピンチと Spotlight のヒントに代わるものです。以前にそれらのヒントを見たことがある場合、ガイドは自動では開きません。
- 自動アップデートはウェルカムガイドが閉じられるまで待機します。

## v1.0.8

### 追加

#### Launchpad
- Homebrew（`brew install --cask`）でインストールしたアプリをアンインストールすると、Homebrew からも削除されるようになりました。アプリと残留ファイルをゴミ箱に入れたあと、AppPad がその cask に対して `brew uninstall --cask` を実行します。Homebrew がない場合や、cask ではないアプリの場合は何も変わりません。
- Homebrew が単独で完了できない場合（cask に管理者パスワードが必要な場合など）、AppPad はターミナルで実行するコマンドを、コピー用のボタンとともに表示します。

#### ワークフロー
- ワークフローパネルで、入力した引数の結果が有効なら緑のチェックマーク、無効なら赤の × で始まるようになりました。

### 変更
- Launchpad からクリップボードまたはワークフローパネルに切り替える際、パネルの影がモーフィングのあとではなく、モーフィング中にフェードインするようになりました。
- パネルの影は AppPad が描画し、常にパネルの外側に表示されます。半透明の背景では、クリップボードとワークフローパネルが Launchpad とまったく同じぼかしと透明度になり、余分に暗くなることがなくなりました。
- ワークフローパネル：有効な引数の結果は緑ではなく通常の文字色で表示されます。無効な結果は引き続き赤で表示されます。
- 別のパネルを開いている状態でメニューバーのメニューから Launchpad、クリップボード、ワークフローを選ぶと、⌘⇧J / ⌘⇧K と同じ方法で切り替わるようになりました。

### 修正
- ⌘⇧J / ⌘⇧K でクリップボードとワークフローパネルを切り替える際に、一瞬ちらつくことがある問題。

## v1.0.0

最初の公開リリース。macOS 26 Tahoe 以降が必要です（Universal：Apple シリコン + Intel）。

### 追加

#### Launchpad
- おなじみのデフォルトレイアウト（あまり使わないシステムアプリは「その他」フォルダにまとめられます）で、クラシックな Launchpad が macOS 26+ に戻ってきました。
- 4 本指のピンチ、メニューバー、または Dock の AppPad をクリックして開きます（もう一度クリックで閉じる）。ピンチのアニメーションはいつでもクリックで取り消せます。
- 2 本指のスワイプでページ移動。ページインジケータはドットまたは数字で表示され、タップしたり、Liquid Glass のレンズでドラッグしてスクラブしたりできます。
- macOS 15 の Launchpad と同じくすぐに検索でき、結果は各アプリの使用頻度と最近使った順で並びます。
- アプリのアイコンを長押しするか ⌥ Option を押したままで編集モード：ドラッグで並べ替え、アプリ同士を重ねてフォルダを作成できます。フォルダは複数ページにまたがることができます。
- クリーンアンインストール内蔵：編集モードでアプリを削除すると、AppPad が残ったファイルも削除します。
- ウインドウサイズは画面に合わせて幅と高さを個別のパーセンテージで設定できます。フルサイズではメニューバーを覆うことができ、ノッチは避けて表示されます。
- マウスのあるディスプレイで開き（オプション）、開いた操作スペースにとどまります。オリジナルの Launchpad と同じ動作です。

#### クリップボード
- テキストと画像のクリップボード履歴を永久に保存します。元のファイルが削除されても画像は残ります。
- よく使う項目のための保存ライブラリ：検索フィールドの横の「保存済み」を切り替えます。保存した項目は検索で最上位に表示されます。
- ⌘. で開き（保存ライブラリ：⌘⌥.）、⌘1–⌘0 でペースト、右側にプレビューを表示します。
- すべての項目にコピー元アプリのアイコンを表示し、よく使うアプリの絞り込みチップと `AppName::` 検索構文を利用できます。
- ⌘↩ で画像の元のフォルダを Finder に表示します。
- 保存ライブラリには触れずに、期間（過去 1 時間、1 日、1 週間…1 年以上）を指定して履歴を整理できます。

#### ワークフロー
- ワークフローパネル（⌘Space）でショートカット、AppleScript、シェルスクリプトを実行し、同じ検索からアプリも起動できます。
- 引数：最初のスペースのあとに入力します（例：`Set-Timer 10:00`）。Tab で選択中の項目を補完します。
- 内蔵ワークフロー：ゴミ箱を空にする、タイマーを設定、アラームを設定、音量を設定、消音、すべてのアプリを終了、そして指数表記に対応した計算機。
- シェルと AppleScript のワークフロー向けに、本物のサンドボックスを備えた権限システム：1回のみ許可 / 許可しない / 常に許可。
- JSON ファイルまたはリンクからワークフローを読み込めます。固有の ID、リビジョン、多言語の名前に対応しています。
- ワークフローごとに成功時と失敗時の通知を設定できます。
- アプリとワークフローは 1 つの使用頻度ランキングを共有します。

#### ウインドウ操作
- ⌃⌥← / ⌃⌥→ で左 / 右に配置し、½ → ⅓ → ⅔ を順に切り替えます。
- ⌃⌥↩ で最大化、⌃⌥⌫ で元に戻す、⌃⌥⌘↑ / ⌃⌥⌘↓ で前 / 次のディスプレイへ移動します。
- すべてのショートカットはカスタマイズできます。

#### アプリのショートカット
- 任意のアプリを開くグローバルショートカット。A–Z のアプリ一覧と競合の検出に対応しています。

#### 外観と一般
- Liquid Glass の検索フィールド、ページインジケータ、設定タブ。
- テーマ：自動 / ライト / ダーク。
- 背景：ホワイト、ライトグレイ、ダークグレイ、壁紙、カスタムカラーから選べ、ライトとダークのテーマごとに透明度とぼかしを個別に設定できます。クリップボードとワークフローパネルは Launchpad の背景に合わせることができます。
- ⌘⇧J / ⌘⇧K で Launchpad、クリップボード、ワークフローをスムーズなモーフィングアニメーションで切り替えます。
- メニューバーのみに常駐し（固定しない限り Dock にアイコンは表示されません）、ログイン時に起動できます。
- 各パネルを開いたときに ABC 入力ソースに切り替えるオプション。
- Esc の動作を設定可能（すぐに閉じる、または先に検索をクリア）。
- 10 言語にローカライズ：English、Deutsch、Español、Français、Italiano、日本語、한국어、Nederlands、简体中文、繁體中文。
